# 🏥 Doctor Appointment Management System

A full-stack web application designed to simplify the doctor appointment booking process. Users can easily find and book appointments with doctors, while doctors and administrators can manage appointments through dedicated dashboards.

## 🚀 Project Overview

The Doctor Appointment Management System provides an efficient platform for managing doctor appointments online.

The system includes three main user roles:

- **Users / Patients** – Browse doctors and book appointments.
- **Doctors** – Manage their appointments and handle booking requests through a dedicated dashboard.
- **Admin** – Manage doctors, monitor appointments, and oversee the overall booking management system.

## ✨ Key Features

### 👤 User / Patient Features
- User registration and login.
- Browse available doctors.
- View doctor details and information.
- Book doctor appointments online.
- Manage and view booked appointments.
- User-friendly interface.


### 🛠️ Admin Dashboard
- Dedicated admin dashboard.
- Manage doctors and doctor information.
- View and manage all appointments.
- Handle booking management.
- Monitor the overall system.

### 📸 Image Management
- Cloudinary integration for image uploading and storage.
- Manage doctor profile images.
